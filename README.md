# 연애 재판 (Love Trial)

데이팅앱의 유입·체류용 보조 콘텐츠로 기획한 미니 게임의 **시연용 데모**입니다. 연애 중 생긴 갈등을 법정 재판 형식으로 코미디화했고, 사용자는 배심원 한 명("나")으로 참여해 재판을 지켜보고 투표한 뒤 판결문을 받아 봅니다. 사용자 외의 인물(재판장, 검사, 변호인, 다른 배심원 6명)은 모두 정해진 대본대로 움직입니다.

## 실행 방법

설치할 패키지나 서버가 없는 정적 웹페이지(HTML 파일 하나)입니다.

### 1. 준비물
- **브라우저:** PC의 Chrome, Edge, Firefox, Safari에서 동작을 확인했습니다. 오래된 버전은 화면이 깨질 수 있으니 최신 버전을 권장합니다(코드 기준 추정 최소 버전: Chrome/Edge 105, Firefox 121, Safari 16.4).
- **소리:** 효과음과 음성이 연출의 일부이므로 스피커나 이어폰을 켜 두세요.
- **화면:** PC 가로 화면 전용입니다. 3:2 비율 무대가 창 크기에 맞춰 늘고 줄어듭니다. 모바일(특히 세로 화면)은 지원하지 않습니다.

### 2. 파일 받기
- Git: `git clone https://github.com/eeeeee-jpg/love-court.git`
- 또는 GitHub 저장소 페이지에서 **Code → Download ZIP**을 눌러 받은 뒤 압축을 풉니다.

### 3. 열기 (셋 중 하나)
- **A. 온라인 배포 주소 (Netlify):** https://lovecourt.netlify.app/
- **B. 로컬 서버로 열기 (권장)**
  - **VS Code Live Server를 쓰는 경우**
    1. VS Code를 설치합니다(https://code.visualstudio.com).
    2. VS Code에서 **파일 → 폴더 열기**로 `love-court` 폴더를 엽니다.
    3. 왼쪽 확장 아이콘을 누르거나 `Ctrl+Shift+X`를 누른 뒤, `Live Server`(게시자 Ritwick Dey)를 검색해 **설치**합니다.
    4. 탐색기에서 `index.html`을 오른쪽 클릭하고 **Open with Live Server**를 고릅니다. 브라우저에 `http://127.0.0.1:5500/index.html`이 열립니다.
  - **Python이 설치된 경우:** `love-court` 폴더에서 `python -m http.server 8000`을 실행하고, 브라우저로 `http://localhost:8000`을 엽니다.
- **C. 파일을 직접 열기 (`file://`):** `index.html`을 더블클릭해도 실행되지만, 브라우저 보안 정책 때문에 다음 기능이 꺼집니다.

| 기능 | `http://` (B) | `file://` (C) |
|---|---|---|
| 효과음 음량 자동 맞춤 | 동작 | 꺼짐, 고정 음량 사용 |
| 법봉 소리 시작 위치 자동 찾기 | 동작 | 파일 처음부터 재생 |
| 캐릭터 일러스트 여백 자동 잘라내기 | 동작 | 이미지 전체 기준으로 배치되어 위치가 달라질 수 있음 |
| 법정 가구 색을 배경에 맞추기 | 동작 | 기본 색 사용 |

### 4. 진행하기
1. 첫 화면은 **역할 선택 카드**입니다. 시연에서는 **배심원**만 고를 수 있습니다. 다른 역할을 누르면 "시연에서는 배심원으로 참여합니다"라는 안내가 나옵니다.
2. **소리:** 브라우저 자동 재생 정책 때문에, 페이지에서 처음 클릭하거나 키를 누르기 전까지는 소리가 나지 않습니다. 역할 카드를 누르는 순간부터 소리가 납니다.
3. 각 단계가 끝나면 화면의 **▶ 버튼** 또는 키보드 **→**로 다음 단계로 넘어갑니다. **◀** 또는 **←**를 누르면 이전 단계를 처음부터 다시 봅니다. 대사가 출력되는 중에 ▶를 누르면 대사를 끝까지 바로 표시합니다(컷인 대사).
4. **평결 투표** 단계에서 A 또는 B를 클릭해 투표합니다.
5. 판결 선고부터 폐정까지는 ▶ 없이 자동으로 이어집니다. 이어서 예고편 팝업이 뜨면 팝업을 클릭해 예고 영상을 재생합니다. 끝 화면의 다시 보기 버튼으로 예고편을, 처음부터 버튼으로 시연 전체를 다시 볼 수 있습니다.

## 용어
- **단계(STAGE):** 재판 진행을 나눈 0~13번 구간입니다. ▶/◀가 이 단계 단위로 움직입니다.
- **배심원의 마음:** 화면 오른쪽 위 게이지입니다. 배심원들이 "무죄 쪽"과 "항의 쪽" 중 어느 쪽으로 기울었는지를 보여 줍니다. 쟁점 주장~평결 투표(6~10단계) 동안 발언한 쪽이 올라가고, 반대쪽은 그만큼 내려갑니다(합계 100).
- **컷인:** 검사·변호인이 핵심 주장을 외칠 때, 화면을 가로지르는 띠 위에 일러스트와 외침 말풍선이 튀어나오는 연출입니다.
- **필터 시연:** 배심원 채팅에서 부적절한 말이 걸러지는 모습을 보여 주는 연출입니다. 실제 욕설은 쓰지 않고 가림 점(●)과 차단 안내만 표시합니다.

## 핵심 흐름

| 단계 | 내용 |
|---|---|
| 0 | 역할 선택 (로고 인트로) |
| 1 | 입장 |
| 2 | 재판장 입장 |
| 3 | 개정 |
| 4 | 사건 소개 |
| 5 | 모두진술 (검사·변호인 첫 주장) |
| 6 | 쟁점별 주장·반박 |
| 7 | 종결 (최종 정리, 재판장의 토론 안내) |
| 8 | 배심원 토론 (채팅) |
| 9 | 채팅 필터 시연 |
| 10 | 평결 투표 |
| 11 | 판결 선고 (재판장 클로즈업) |
| 12 | 반응 + 폐정 |
| 13 | 예고편 (팝업, 예고 영상) |

- **사건:** "12시간 연락두절 사건"(고정 시나리오)
- **선택지:** A 무죄 / B 항의 정당
- **투표:** 배심원 7명(나 + 6명)이 투표해 동점이 없습니다. 다른 배심원 6명의 표가 A 4표, B 2표로 정해져 있어, 내가 어느 쪽을 골라도 **결과는 항상 A 무죄**입니다. 재판장이 판결문을 낭독한 뒤 법봉을 세 번 치고 판결 도장을 찍습니다.

## 주요 기능

- **법정 연출:**
  - 평소에는 위에서 내려다본 법정(탑뷰) 화면이고, 재판장이 말할 때(개정, 사건 소개, 토론 안내, 판결 선고, 폐정) 정면 클로즈업 화면으로 전환됩니다.
  - 검사·변호인의 핵심 주장은 일러스트 컷인으로 연출됩니다. 쟁점 1과 쟁점 2에서 서로 다른 일러스트를 씁니다.
  - 인물은 픽셀 아바타로 걷고, 앉고, 말합니다.
  - 발언자별로 카메라가 따라가는 연출(화자별 클로즈업)은 아직 없습니다.
- **대화창과 재판 기록:** 대사를 타자 치듯 한 글자씩 보여 주고, 대사 기록이 채팅창에 쌓입니다.
- **배심원 토론 채팅:** 다른 배심원들의 채팅(대본)과 필터 시연을 보여 줍니다. 사용자가 직접 입력하지는 않습니다.
- **"배심원의 마음" 게이지:** 위 용어 설명 참고.
- **평결 투표:** 배심원 머리 위에 진행 마크(? → 체크 / A / B)가 상태별 색으로 표시되고, 7명 투표가 끝나면 알림음이 울립니다.
- **판결 선고:** 재판장 클로즈업, 판결문 낭독(음성 길이에 맞춰 글자 표시), 법봉 3회, 판결 도장.
- **효과음:** 법봉, 입장 전 웅성거림, 채팅 타이핑, 필터 경고음, 컷인 효과음, 투표 완료 알림음, 예고편 효과음.
- **음성:** 사전 제작한 음성 파일입니다.
  - 재판장: 개정, 사건 소개, 토론 안내, 판결문, 폐정 (5개)
  - 검사·변호인: 컷인 외침만 (4개)
  - 그 밖의 대사는 소리 없이 자막으로만 나옵니다.
- **재생 컨트롤:** ◀/▶ 버튼 또는 키보드 ←/→. 역할 카드에서는 ↑/↓로 항목을 이동합니다.
- **예고편:** 다음 사건("핫팩 사건") 예고 팝업이 뜨고, 팝업을 클릭하면 예고 영상이 재생됩니다. 끝 화면에 다시 보기와 처음부터 버튼이 있습니다.

## 기술 스택

- 순수 HTML/CSS/JavaScript 단일 파일(`index.html`)
- 외부 라이브러리, CDN, 빌드 도구 없음
- 서버·API 호출 없음. 페이지가 읽는 파일은 같은 폴더의 `images/`, `fonts/`, `sounds/`뿐입니다.
- 브라우저 내장 기능: Web Audio API(효과음 분석·재생), FontFace API(픽셀 폰트 로딩), CSS 컨테이너 쿼리 단위(화면 크기 맞춤)


## 안정성

- **외부 요청 없음:** 모든 연출이 고정 데이터로 동작해서, 외부 요청 실패로 생기는 오류가 없습니다.
- **단계 이동 시 이전 연출 중단:** ◀/▶로 단계를 옮기면 진행 중이던 애니메이션, 타이머, 효과음, 음성을 모두 멈춥니다. 이전 단계의 늦게 끝난 동작은 세대 번호(`gen`)로 걸러내 무시합니다. 이동한 단계의 화면 상태(인물 위치, 채팅 기록, 투표 상태)는 처음부터 다시 만듭니다.
- **멈춤 방지 타이머:** 사용자 입력을 기다리는 단계(역할 선택, 투표, 예고편 팝업)를 빼고, 어떤 단계든 60초 안에 끝나지 않으면 ▶ 버튼을 강제로 켭니다(`SAFETY_UNLOCK_MS`).
- **단계 오류 격리:** 한 단계에서 오류가 나면 콘솔에 기록하고 ▶를 켜서, 다음 단계로 넘어갈 수 있게 합니다.
- **소리 실패 시 계속 진행:** 오디오 파일을 불러오지 못하거나 자동 재생이 막히면 경고만 남기고 소리 없이 진행합니다. 녹음이 없으면 대사는 기본 대기 시간으로 넘어갑니다. 입장 전 웅성거림은 첫 클릭 때 다시 재생을 시도합니다.
- **`file://` 대비:** 파일 분석(음량 맞춤, 법봉 시작점, 이미지 여백·색 분석)이 막히면 미리 정한 값으로 대신합니다.
- **이미지 누락 대비:** 일러스트 파일이 없으면 픽셀 아바타로, 쟁점 1용 새 일러스트가 없으면 기본 일러스트로 대신합니다.
- **입력 방어:**
  - 투표 버튼은 한 번 누르면 모두 비활성화되어 중복 투표가 되지 않습니다.
  - 채팅 입력칸은 읽기 전용이라 사용자가 입력할 수 없습니다.
  - 데모에서 허용하지 않은 역할은 고를 수 없고 안내만 나옵니다.
- **값 범위:** 게이지 값은 0~100 사이로 제한됩니다. 투표자는 7명(홀수)이라 동점이 생기지 않습니다.

## 알려진 한계

- 고정 시나리오("12시간 연락두절 사건")로만 동작하는 시연용입니다. 결과도 항상 A 무죄입니다.
- 검사·변호인의 일반 대사에는 음성이 없습니다(컷인 외침만 음성).
- 발언자 클로즈업 연출과, 그에 필요한 검사석·변호인석 배경 이미지는 아직 없습니다.
